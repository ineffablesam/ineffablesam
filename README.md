### Recent work

**[Loupe](https://github.com/ineffablesam/loupe-extension)**: A Chrome extension concept for Perpay. It reads any product page, shows the price in paychecks and hours of work, and reads the fine print with Gemini Nano on-device. [Demo](https://youtu.be/eFXTPHeqPCM)

**[Accord](https://github.com/ineffablesam/accord-ai)**: A multi-agent coding workspace on an infinite canvas. A planner agent hands work to specialist agents, and each project runs in its own Docker container with a live editor, terminal and preview. [Demo](https://youtu.be/O3XSHkfqPwI)

**[CODI](https://github.com/ineffablesam/codi)**: Build and deploy apps from your phone. A coding agent writes, commits and ships Docker previews, and a browser agent streams back to the phone. 3rd place, Serverpod Flutter Butler Hackathon 2026.

**[ShowOnce](https://github.com/ineffablesam/showonce)**: Record a web task once and let someone else, or a browser agent, replay it on their own account. The agent can't submit anything without a human click.

**[ExecuTorch Bridge for Flutter](https://pub.dev/packages/executorch_bridge_flutter)**: An open-source Flutter plugin for running Llama models locally on iOS, with token streaming and memory monitoring. Android is in development.
